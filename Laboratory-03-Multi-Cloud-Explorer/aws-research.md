# AWS Research

## 1. Brief Overview

Amazon Web Services (AWS) is a cloud computing platform provided by Amazon. It offers many cloud services that organizations can use without having to build and maintain all their own physical servers.

## 2. Global Infrastructure

AWS has a global infrastructure made up of Regions and Availability Zones. These allow organizations to run applications and store data in different geographic locations.

## 3. Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services. Users can use the console to create, configure, and monitor cloud resources.

## 4. Four Core Services

1. Amazon EC2 – provides virtual servers for running applications.
2. Amazon S3 – provides cloud object storage for files and data.
3. Amazon VPC – provides networking for AWS resources.
4. AWS IAM – manages users, permissions, and access to AWS resources.

## 5. Three Advantages

1. AWS offers a wide range of cloud services.
2. AWS can scale resources based on business needs.
3. AWS has a large global infrastructure.

## 6. Typical Enterprise Use Cases

AWS can be used by businesses for web applications, data storage, backup and recovery, databases, and large-scale applications.
