# Cloud Computing Reflection

Every day, I use different cloud services without realizing how important cloud computing is. Three cloud services I often use are Google Drive, Facebook Messenger, and Canva.

Google Drive is an example of Software as a Service (SaaS) because I use it directly through my browser or phone without installing or managing servers. It uses a Public Cloud since many users can access the service over the internet.

Facebook Messenger is also SaaS because it allows me to send messages, make voice calls, and share files online. It also runs on a Public Cloud because millions of users access it through the internet.

Canva is another SaaS application that helps me create presentations, posters, and school projects. Like the others, it is hosted on a Public Cloud and is available to anyone with an internet connection.

Git and GitHub are important when working on cloud projects because they keep track of every change made to files. If someone makes a mistake, previous versions can easily be restored. GitHub also allows multiple people to work together without accidentally overwriting each other's work. Team members can review changes, suggest improvements, and keep all project files organized in one place.

After learning about cloud computing, I realized that many of the applications I use every day are powered by cloud technology. Understanding service models, deployment models, and version control helps me appreciate how modern technology works and prepares me for future projects in Information Technology.
